Bienvenue sur Ben Workspace

Cet outil te permet de gérer la prospection des clubs dans un tableau intelligent. Tes données sont sauvegardées automatiquement dans le cloud (Supabase) après chaque modification.

1. Les 12 colonnes du tableau

Le tableau contient 12 colonnes de base, dans cet ordre :

  • Nom du club — nom complet du club.
  • Région — région administrative (Auvergne-Rhône-Alpes, etc.).
  • Département — numéro ou nom du département.
  • Site du club — URL du site officiel.
  • Nom — nom du contact dans le club.
  • Rôle — rôle du contact (menu déroulant : président, coach, etc.).
  • Téléphone — numéro de téléphone.
  • Mail — adresse e-mail.
  • Statut de la prospection — menu déroulant coloré (à contacter, en cours, signé...).
  • Date premier contact — date du premier échange.
  • Date dernière action — date de la dernière interaction.
  • Commentaires — notes libres.

Tu peux ajouter d'autres colonnes personnalisées via le bouton « Ajouter une colonne ».

2. Modifier les cellules

  • Cellules texte / date / nombre — double-clique pour passer en mode édition, tape ta valeur, puis Entrée pour valider ou Échap pour annuler.
  • Menus déroulants (Rôle, Statut) — un seul clic suffit, choisis dans la liste, c'est sauvegardé instantanément.
  • Navigation clavier — en mode édition, utilise les flèches pour passer de cellule en cellule, Entrée pour descendre d'une ligne.

3. Codes couleur du statut

  • à contacter — aucun contact établi.
  • en cours — échange en cours.
  • rdv fixé — rendez-vous programmé.
  • proposition envoyée — offre transmise.
  • signé — contrat signé.
  • pas signé — proposition refusée.
  • à relancer — à relancer après silence.

4. Ajouter / supprimer une ligne

  • Clic sur « + Ajouter une ligne » dans la barre d'outils. La ligne apparaît en tête de tableau avec : Rôle = aucune des catégories et Statut = à contacter par défaut.
  • Pour supprimer : clic sur une ligne pour la sélectionner (une barre bleue apparaît à gauche), puis le bouton « Supprimer la ligne » au-dessus du tableau s'active.

5. Filtrer et trier

Clique sur « Filtres » pour ouvrir le panneau. Tu peux :

  • Filtres rapides — tris alphabétiques (Nom A→Z / Z→A), tri par date dernière action, et 4 menus déroulants pour filtrer par Région, Département, Rôle ou Statut.
  • Filtres avancés — clic sur « Ajouter un filtre » pour combiner plusieurs critères avec les opérateurs : égal à, contient, commence par, est vide, n'est pas vide.
  • Recherche globale — le champ de recherche en haut filtre sur toutes les colonnes.
  • Tri par colonne — clic sur l'en-tête d'une colonne pour trier (1er clic = croissant, 2e = décroissant, 3e = neutre).
  • Réinitialiser — bouton qui efface filtres, tri et recherche d'un coup.

6. Gérer les colonnes

  • Ajouter — bouton « Ajouter une colonne », choisis le type (texte, nombre, date, liste, case à cocher, tag) et la valeur par défaut.
  • Modifier / supprimer / réorganiser — bouton « Gérer les colonnes ».
  • Drag & drop dans les en-têtes pour réordonner directement.
  • Redimensionner — glisse la poignée droite d'une en-tête.

7. Importer un PDF

L'app peut extraire un PDF type FFR (liste de clubs) et mapper les données dans Nom du club / Région / Département. Les 9 autres colonnes seront créées vides avec leurs valeurs par défaut.

⚠️ L'import écrase les données existantes du tableau (une confirmation t'est demandée).

8. Exporter en CSV

  • Numbers (CSV compatible) — séparateur ; + BOM, ouvre direct dans Numbers/Excel français.
  • CSV standard — séparateur ,.
  • Choix de la source : tableau complet ou vue filtrée actuelle.
  • Limite optionnelle du nombre de lignes.

9. Partager en lecture seule

Le bouton Partager génère un lien public qui montre la vue actuelle. Personne ne peut modifier les données via ce lien. Idéal pour transmettre un extrait à un collègue.

10. Sauvegarde automatique

Toute modification (cellule, ajout/suppression de ligne ou colonne, filtre…) est sauvegardée automatiquement dans Supabase en quelques secondes. Aucun bouton « Sauvegarder » à cliquer.

Si tu vois un toast orange « Sauvegarde automatique indisponible », vérifie la connexion réseau ou la configuration Supabase (variables d'environnement).

Astuces

  • La 1re colonne (Nom du club) reste figée pendant le scroll horizontal.
  • Le clic sur une ligne la sélectionne (utile avant « Supprimer la ligne »).
  • Les lignes sont alternées blanc/bleu pour la lisibilité.
  • Au survol d'une ligne, elle se surligne en bleu.

Tu as fait le tour ! Lance-toi dans la prospection.
